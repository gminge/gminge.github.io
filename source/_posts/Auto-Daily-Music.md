#### 以下来自ai

方式二：纯粹极客“硬核自动化”（GitHub Actions + Python 脚本）

如果你觉得每天点一下手机太不酷了，想要真正的“无人值守”更新，这也是可以做到的，但需要你具备一点折腾精神。

**实现原理：**

1. 获取你网易云账号的底层 **Cookie**。

2. 在 GitHub 仓库里写一个 **Python 脚本**。

3. 配置 **GitHub Actions**（免费的云端服务器），让它每天凌晨 6:00 自动起床。

4. 它会拿着你的 Cookie 模拟登录网易云，抓取今天的每日推荐，然后通过 API 把这些歌强行塞进你的《博主的每日推荐》公开歌单里。

**你需要付出的代价：** 你需要去抓包获取 Cookie，并且网易云的 Cookie 偶尔会失效，每隔一两个月你可能就要重新抓取一次去替换
